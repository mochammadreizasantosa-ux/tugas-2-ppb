🛒 Rezz Store - Ultimate E-Commerce App
Aplikasi toko online modern berbasis Flutter yang dirancang untuk memberikan pengalaman berbelanja intuitif, cepat, dan responsif. Aplikasi ini terintegrasi langsung dengan REST API untuk pengelolaan data produk secara real-time.
🎨 Konsep Desain & Tema Warna
Aplikasi ini mengusung konsep antarmuka Cyber-Modern Midnight, memberikan kesan elegan, futuristik, dan nyaman di mata untuk penggunaan jangka panjang.

Midnight Eclipse (#0F172A): Warna latar belakang utama yang memberikan kesan mendalam.

Neon Electric Blue (#3B82F6): Warna aksen utama untuk tombol interaktif dan highlight.

Cyan Glow (#06B6D4): Digunakan untuk penanda status dan elemen sekunder.

Soft Obsidian (#1E293B): Warna komponen kartu produk dan kontainer data.
Fitur Utama Aplikasi
1. Etalase & Katalog Produk (Home Screen)
Kategori Dinamis: Pemfilteran barang berdasarkan kategori secara instan.

Integrasi Live API: Pengambilan data produk, harga, dan stok dari layanan REST API.

Pencarian Cepat: Fitur pencarian produk real-time berbasis nama atau merek.
2. Rincian Produk (Product Detail Screen)
Galeri Gambar Interactive: Tampilan visual produk berkualitas tinggi.

Spesifikasi & Deskripsi: Penjelasan detail barang beserta ulasan pelanggan.

Quick Action Button: Akses cepat untuk menambahkan barang ke keranjang atau langsung ke menu pembayaran.
3. Manajemen Keranjang & Transaksi (Cart & Checkout)
Kalkulasi Otomatis: Perhitungan total harga produk beserta pajak secara akurat.

Manajemen Jumlah: Kemudahan menambah atau mengurangi unit barang secara fleksibel.
